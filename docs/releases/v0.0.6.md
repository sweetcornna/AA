# v0.0.6 发布说明

Android versionCode 为 6，沿用既有 application ID 和 release 证书；Web 与后端使用同一提交。

- 修复退出圈子，加入结余拦截、圈主转让、历史参与者展示及并发保护。
- 删除聊天助手，保留一句话记账、语音输入、规则回退和普通结算。
- 更新响应式原生界面、SVG、动画和「同享」标志。
- 修复跨账号缓存、分摊成员选择、深链和录音取消/恢复。
- APK 校验覆盖全部分块资源，逐文件验证其完整压缩内容确实包含在当前原生包中，拒绝旧 Cargo 缓存和缺失懒加载页面。

本轮用户明确要求不执行验证码验收，以代码复核作为该项发布依据。因此未运行需要 OTP 的生产业务 canary，真实生产验证码与云端语音转写不标记为通过。现有 canary 脚本的默认保护保持不变。静态检查、自动化回归、数据库备份/恢复验证、生产健康与公开密钥检查照常执行。

物理 Android 真机仍未验收，沿用现有发布流程的明确披露路径。详情见 [改版回归记录](../UI_REDESIGN_QA.md) 和 [标志验收](../brand/README.md)。

CI 的 Linux WebKit 未提供 MediaRecorder，验证其提示与手动记账恢复，不把录音采集计为该环境已通过；macOS WebKit 的实际录制路径已在本地覆盖。Linux Firefox 使用虚拟音频输出运行真实 Web Audio / MediaRecorder 测试。

后端先追加 `0014_circle_departure.sql`，再切换不可变函数产物，最后发布 Web 与经验证的 Android 签名候选。既有迁移与业务历史不删除、不重置。
